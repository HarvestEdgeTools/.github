# Harvest Edge Tools

Software and automation for **Baptist ministry** in Central Florida and beyond — built with care for local church autonomy, the Baptist Faith & Message 2000, and transparent engineering.

**Public home:** [harvestedgetools.com](https://harvestedgetools.com)

**What we build**

- **HET Core** — shared cloud-agent environments, platform verify, and migration tooling for the HET estate.
- **Baptist Ministry Factory** — internal factory for agents, Brain (HOKMAH), and ministry-adjacent automation (desk-first; not a public product surface).
- **LCBA Site** — [Lake County Baptist Association](https://lakebaptist.org) web presence and member-church tooling.
- **Framework & shared resources** — cross-repo rules, skills, and patterns for HET builders.
- **AMS Tool Library** — association news and tooling paths tied to ministry communications.

We favor small, named gates, read-only desk audits, and HOKMAH-first documentation over big-bang rewrites.

**Repositories on GitHub:** This organization keeps its code **private** until individual projects are ready for a public surface. **No public repo pins** on the org profile until Timothy names them.

**Contact / governance:** Solo maintainer org; sensitive deploy repos use stricter review (LCBA parachute). Questions about public sites: use channels listed on [harvestedgetools.com](https://harvestedgetools.com).
